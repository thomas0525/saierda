# 奥特曼传说：光之荒野

一款浏览器里的 3D 开放世界动作冒险游戏 —— 奥特曼版的《塞尔达传说》。电脑和手机都能玩，无需安装。

**▶ 在线游玩：https://thomas0525.github.io/saierda/**

## 玩法

- 开局从 5 位奥特曼中选择一位：初代奥特曼、赛文、迪迦、赛罗、捷德，每位的属性和必杀技都不同
- 在开放世界中自由探索：草原、森林、沙漠、雪山、湖泊、人类小镇
- 击败占据 4 座光之塔的守护怪兽（哥莫拉、雷德王、艾雷王、杰顿），收集 4 块光之碎片
- 集齐碎片后，北方暗黑城的结界会消失，在城里挑战最终 Boss **极恶贝利亚**（血量过半后进入觉醒形态）
- 地图上散落着 12 个宝箱，能提升最大生命和攻击力
- 进度自动保存在浏览器本地

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD | 左侧虚拟摇杆（推远可冲刺） |
| 视角 | 鼠标（点击画面锁定） | 右侧滑动 |
| 跳跃 / 飞行 | 空格（空中长按飞行） | 「跳」键（长按飞行） |
| 冲刺 | Shift | 摇杆推远 |
| 三段连击 | J / 鼠标左键 | 「拳」键 |
| 必杀技 | K / 鼠标右键 | 「光」键 |
| 闪避（无敌帧） | Q / L | 「闪」键 |
| 地图 | M / 点击小地图 | 点击小地图 |
| 暂停 | Esc | 右上角暂停键 |

## 技术

纯静态页面：Three.js（通过 CDN 加载）+ 原生 ES Modules，不需要构建步骤。所有模型都由代码程序化生成，音效和音乐用 WebAudio 实时合成。

本地运行：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
